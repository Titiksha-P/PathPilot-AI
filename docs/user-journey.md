# End-to-End User Journey

## Journey Goal

Move a student from **uncertainty** to a **defensible career decision and an immediate action plan**.

## Stage 1 — Guided Onboarding

The platform collects only the information required for a meaningful first recommendation:

- education level
- preferred subjects
- interests
- current skills
- career goals
- learning preferences
- practical constraints

### UX rule
Each question must explain why it is being asked. This improves trust and reduces the feeling of completing another generic aptitude test.

## Stage 2 — Profile Intelligence Summary

Before recommending a career, the system reflects the profile back to the student:

- strongest interests
- strongest current capabilities
- preferred way of learning
- important constraints
- areas where the profile is uncertain

The student can correct the summary before continuing.

## Stage 3 — Explained Career Recommendations

The system returns the top three career matches. Every card should contain:

- career title
- match score
- confidence level
- strongest reasons for the match
- matched skills
- top missing skills
- estimated readiness level
- primary action button

### Primary actions

- Explore career
- Compare
- View skill gaps
- Build roadmap

## Stage 4 — Career Decision Simulator

The student selects two careers and receives a personalized comparison.

Comparison dimensions:

- personal interest alignment
- current skill alignment
- education compatibility
- learning effort
- time-to-readiness
- major skill gaps
- opportunity relevance
- first recommended action

The result should not declare one universal winner. It should explain the trade-off and identify which path is more suitable under the student's current priorities.

## Stage 5 — Skill-Gap Analysis

The platform divides capabilities into:

- already demonstrated
- partially developed
- missing but essential
- useful but optional

Each missing skill must be linked to:

- why it matters
- suggested learning resource
- evidence of completion
- estimated effort

## Stage 6 — Personalized 90-Day Roadmap

The roadmap converts the recommendation into a realistic sequence:

### Days 1–30: Foundation
Build essential knowledge and complete one beginner-level outcome.

### Days 31–60: Application
Use the acquired skills in a guided project, exercise, or case study.

### Days 61–90: Proof
Create portfolio evidence, complete an assessment, or produce a demonstrable outcome.

## Stage 7 — Feedback and Adaptation

The student can respond to a recommendation using:

- This feels accurate
- I am interested, but not ready
- This does not fit me
- Show another direction

Feedback should update future rankings rather than functioning as a decorative button.

## Alternate Paths

### Insufficient profile data
Ask targeted follow-up questions instead of producing a low-quality recommendation.

### Conflicting signals
Show that the profile contains competing preferences and ask the student to rank priorities.

### Student already has a target career
Skip general discovery and perform suitability, skill-gap, and roadmap analysis for that career.

### Student rejects all recommendations
Explain which inputs influenced the result and allow profile correction.

## Demo Success Criteria

The user journey succeeds when a judge can see:

1. what the student entered,
2. how those inputs affected the recommendation,
3. why the recommendation was produced,
4. what trade-offs exist,
5. and what the student should do next.
